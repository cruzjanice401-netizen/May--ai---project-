# AI-Powered Fish Population Estimator
 Building AI course project
 ## Summary
 This simple Python program calculates the percentage of fishers relative to the total population across Nordic countries. It demonstrates basic data processing and arithmetic operations — a foundational step toward understanding how AI systems handle and analyze real-world datasets.
 ## Background
 Understanding population and resource distribution is important for sustainable development, especially in coastal communities where fishing is a key industry. Many people may not realize how small differences in data can reveal meaningful insights about livelihoods and economic activity. This project started as a learning exercise to make data more approachable and understandable for everyone, regardless of technical background.
 * Problem: Raw numbers are hard to interpret and compare across different countries
 * Problem: Manual calculations are prone to error and time-consuming
 * Personal motivation: I want to learn how AI and data tools can help make information clearer and more useful for everyday decisions
 ## Data sources and AI methods
 * Data: The example dataset includes population and fisher numbers for Denmark, Finland, Iceland, Norway, and Sweden. These are illustrative figures based on general knowledge; for a real application, official statistics from national bureaus would be used.
 * Tools: Python is used here for basic calculations and printing results. This demonstrates the kind of data processing that forms the foundation of more complex AI and machine learning workflows.
 ## How is it used?
 The program runs in a simple command-line or Python environment. When executed, it reads the data, computes total values, then calculates and displays the proportion of fishers for each country. It's intended for educational purposes — anyone learning programming or data analysis can use it to practice working with lists, loops, and basic statistics. It could be expanded to include more countries, time periods, or visual charts.
 ## Challenges
 This is a very basic demonstration — it does not use machine learning, make predictions, or handle uncertainty. The data is simplified and should not be used for policy or business decisions. Ethical considerations include ensuring data accuracy, not over-interpreting simple percentages, and being transparent about how calculations are done.
